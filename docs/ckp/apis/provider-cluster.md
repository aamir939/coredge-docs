# CKP Provider Cluster APIs

CKP exposes REST APIs for managing provider cluster configurations:

| API Category | Operations |
|--------------|------------|
| Provider Cluster CRUD | Create, update, and delete provider cluster configurations |
| Provider Cluster Lookup | Retrieve by name, by cluster ID, or list all within a domain or project |
| Provider Validation | Check whether a domain has a provider cluster configured |
| Unscoped Queries | List all provider clusters across domains (platform-level) |
