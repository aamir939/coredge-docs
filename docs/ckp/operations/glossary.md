# Glossary of Abbreviations

The following abbreviations and acronyms are used throughout the CKP documentation:

| Abbreviation | Full Form |
|--------------|-----------|
| API | Application Programming Interface |
| BMS | Baremetal Server |
| BYOH | Bring Your Own Host |
| CA | Certificate Authority |
| CAPI | Cluster API (Kubernetes Cluster Lifecycle Management) |
| CIDR | Classless Inter-Domain Routing |
| CNCF | Cloud Native Computing Foundation |
| CKP | Coredge Kubernetes Platform (Coredge Kubernetes Platform) |
| CNI | Container Network Interface |
| CRD | Custom Resource Definition |
| CRI | Container Runtime Interface |
| CRUD | Create, Read, Update, Delete |
| CSI | Container Storage Interface |
| DNS | Domain Name System |
| eBPF | Extended Berkeley Packet Filter |
| gRPC | Google Remote Procedure Call |
| K8s | Kubernetes |
| mTLS | Mutual Transport Layer Security |
| OCI | Open Container Initiative |
| PGP | Pretty Good Privacy |
| PSK | Pre-Shared Key |
| REST | Representational State Transfer |
| TLS | Transport Layer Security |
| UI | User Interface |
| VM | Virtual Machine |
| YAML | YAML Ain't Markup Language |
